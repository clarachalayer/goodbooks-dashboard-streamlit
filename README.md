# 📚 Goodbooks Dashboard

Dashboard interactif d'analyse exploratoire sur le dataset [goodbooks-10k](https://github.com/zygmuntz/goodbooks-10k), qui regroupe 10 000 livres parmi les plus notés sur Goodreads.

## Fonctionnalités
- **EDA :** aperçu du dataset et statistiques descriptives
- **Insights :** top 10 des auteurs les plus représentés, distribution des notes moyennes avec un histogramme interactif (nombre de classes réglable)
- **Prédiction :** en cours de développement

## Stack
Python · Streamlit · pandas · Plotly

## Lancer l'application
```bash
pip install -r requirements.txt
streamlit run main.py
```
Les données sont chargées directement depuis le dépôt source, aucun téléchargement n'est nécessaire.
